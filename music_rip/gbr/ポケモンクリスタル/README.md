# ポケモンクリスタルのGBR(sound file)を生成するパッチ

クリスタルのROMにGBRヘッダと初期化ルーチンをくっつけただけ

通常モノラル版と、ステレオ設定版の2つ

# 使い方
1. カートリッジからROMを吸い出す --> FT-GBDumperとか
2. ROMに本パッチを当てる --> Floating IPS patcherとか
3. パッチを当てたファイルの拡張子を.gbrにする
4. 適当なプレイヤーで再生する --> TraySoundPlayerとか
