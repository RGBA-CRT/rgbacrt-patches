# パソファミで抜き出したMADARAのNSFがDPCMならない問題を修正するパッチ

パソファミで抜き出したNSFの$F000-$FFFFは拡張ルーチン置き場(NSF bank 8)で先頭数バイト以外は0x00 fillされるが、
DPCMは$FE00-$FFCFに配置されるので鳴らない。
(DPCMレジスタに書く内容$FFD0-4バイトずつも0になるので、DMC lengthも0になって鳴らない)

このパッチでは
本来のDPCMが含まれるバンク(NSF bank 3)を正しく$F000-に配置の上、
拡張ルーチン(INIT, hook?の2つ)を$F110-に移動することでDPCMがなるようにした。

# 使い方
1. カートリッジからROMを吸い出す --> Kazzoなど
2. ROMからNSFを吸い出す --> パソファミ
3. 本パッチを当てる
